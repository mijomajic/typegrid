# TypeGrid

- Count events only. Never inspect keys, text, window titles, paths, clipboard, or URLs.
- Keep the native agent dependency-free and web architecture small.
- All personal data APIs require server-side authorization. New profiles are public by default, with an explicit visibility choice before installation. Preserve existing users’ privacy choices.
- Run npm test, npm run typecheck, npm run build, and Swift tests for relevant changes.
- Never commit credentials, local databases, or user telemetry.
