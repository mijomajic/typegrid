# Contributing

Small is a feature. Open an issue before adding major product surface area. Good first contributions: native Linux/Windows counter implementations, accessibility improvements, platform testing, and privacy-reviewed metrics-only integrations.

Run `npm ci`, configure `.env.local`, migrate a dedicated development database, and start `npm run dev`. The agent is a dependency-free Swift package under `agent/`.

Run the checks documented in README. Explain behavior and relevant validation in your PR. Never include real user activity, tokens, keys, prompts, key codes, or window titles in fixtures or bug reports. Screenshots should use clearly labeled demonstration data or your explicit opt-in data.

We will decline raw key logging, productivity surveillance, employee ranking, screenshot capture, and private-account scraping. Keep the core usable without integrations.
